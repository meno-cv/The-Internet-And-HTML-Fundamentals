Internet

What is the Internet

The Internet is a vast network of interconnected computers that allows for the sharing of information and communication across the globe.

As technology continues to advance, the Internet continues to grow and improve. It supports education, business, healthcare, and many other industries. Because of its importance, the Internet has become one of the most valuable inventions in modern history

How does the Internet Work?

    Client-Server Model

    The Client-Server Model is a communication system used on the Internet. A client, such as a web browser, sends a request to a server. The server processes the request and sends the required information back to the client.

    HTTP

    HTTP (HyperText Transfer Protocol) is the set of rules used for transferring web pages and data between a browser and a web server. It allows users to access websites and view online content.

    DNS

    DNS (Domain Name System) translates domain names such as www.google.com into IP addresses that computers can understand. This helps users access websites without remembering complex numbers.

Domain Name System (DNS)

What is DNS?

The Domain Name System (DNS) is like the phonebook of the internet. It converts human-friendly domain names (like www.google.com) into IP addresses that computers use to locate websites.

How DNS Works

When you enter a website name, your browser checks for its IP address. If it doesn’t know it, a request is sent to a DNS server which finds and returns the correct IP address so the website can load.

Examples
  • www.google.com → IP address
  • www.youtube.com → IP address
  • www.facebook.com → IP address

DNS Flow

User → Browser → DNS Resolver → Root Server → TLD Server → Authoritative Server → IP Address → Website Loads
